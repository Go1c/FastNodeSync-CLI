# FNS v3.5.1 分页控制协议适配实现计划 (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 FastNodeSync-CLI 客户端适配 FNS Server v3.5.1 的分页（Page）同步控制协议，在 `NoteSync`、`FileSync`、`SettingSync` 与 `FolderSync` 四个同步模块实现主动分页握手（`*SyncPageAck` 与 `*SyncPage` 控制处理）。

**Architecture:** 采用模块独立自治模式（方案一），无需创建基类或复杂继承；分别在 4 个模块中维护顶层 `context/vault` 上下文、添加 `_send_page_ack` 响应方法和 `_on_sync_page` 处理器，按“到达即应”方式驱动服务器下发分页流，并依托原有收齐计数判定同步完成。

**Tech Stack:** Python 3.10+, pytest, pytest-asyncio, websockets, dataclasses

## Global Constraints

- 遵循现有异步 `WSMessage` 编解码与事件注册（`ws.on`）风格；
- 绝不破坏 `_on_sync_modify`、`_on_sync_delete` 已有的数据持久化与冲突处理逻辑；
- 每次收到 `*SyncPage` 与 `_on_sync_end` 后精准调用既有的 `_check_all_received` 或 `_check_complete`，确保各链路收齐校验条件不回退。

```python
    async def _on_sync_end(self, msg: WSMessage) -> None:
        data = _extract_inner(msg.data)
        if isinstance(msg.data, dict):
            self._sync_context = msg.data.get("context", "")
            self._sync_vault = msg.data.get("vault", "")

        self._expected_modify = data.get("needModifyCount", 0)
        self._expected_delete = data.get("needDeleteCount", 0)
        self._got_end = True
        log.info(
            "← FolderSyncEnd (needModify=%d, needDelete=%d)",
            self._expected_modify,
            self._expected_delete,
        )

        total_expected = self._expected_modify + self._expected_delete
        if total_expected == 0:
            self._sync_complete = True
        else:
            await self._send_page_ack(self._sync_context, -1, self._sync_vault)
            self._check_all_received()

    def _check_all_received(self) -> None:
        if not self._got_end:
            return
        total_expected = self._expected_modify + self._expected_delete
        total_received = self._received_modify + self._received_delete
        if total_received >= total_expected:
            log.info("FolderSync complete: %d modified, %d deleted", self._received_modify, self._received_delete)
            self._sync_complete = True
```

```python
        self._check_all_received()

        # 在 _on_sync_delete 末尾

        self._check_all_received()
```
